Arsitektur Pipeline

Input teks → Detect Dialect
joblib LogReg (Django) → Translate + Summarize + NER
Modal (NLLB / mT5 / IndoT5 / NER) → Category + Urgency
keyword matching (Django) → NLPResult
Kalau Modal tidak terjangkau, Django langsung pakai pipeline lokal (deep_translator/TextRank/regex) — aduan tetap selesai, hanya kualitasnya lebih rendah.

Pipeline Information

Model neural (translate/summarize/NER) jalan di layanan Modal terpisah, dipicu lewat trigger HTTP dan hasilnya dikirim balik lewat callback. Dashboard ini hanya menjalankan pipeline lokal (fallback) untuk eksperimen — hasil test tidak disimpan ke database.

Input

Teks aduan bebas: Bahasa Indonesia atau dialek daerah.

Dialect

Selalu lokal — joblib LogReg, tidak butuh Modal.

Neural (Modal)

Translate, summarize, entity extraction lewat NLLB/mT5/IndoT5/NER.

Fallback (Django)

deep_translator/TextRank/regex kalau Modal tidak terjangkau.

Dialect Detector

Trained local

Backbone
Scikit-learn Pipeline: TF-IDF vectorizer + Logistic Regression classifier.

Dataset
Dataset dialek lokal project dari sampel NusaX/multidialect untuk 12 kelas dialek.

Preprocessing
Lowercase ringan, TF-IDF character/word features sesuai model training, probabilitas kelas via `predict_proba`.

Fallback
`langdetect`, lalu `xx` jika teks pendek atau confidence terlalu rendah.

Translation

Modal

Backbone
`facebook/nllb-200-distilled-600M`, jalan di Modal (../../nlp-service/).

Preprocessing
Mapping kode dialek ke FLORES-200 language code, truncate input, target token `ind_Latn`.

Fallback lokal
deep_translator/googletrans kalau Modal tidak terjangkau; aktif hanya jika `ALLOW_EXTERNAL_TRANSLATION=true`.

Summarization

Model utama (mT5/IndoT5) dikonfigurasi lewat `SUMMARIZER_MODEL` di deployment Modal, bukan di Django.

mT5-base / IndoT5 NusaSum

Checkpoint
`OinoVenv/sovereign-mt5-nusasum` / `OinoVenv/sovereign-indot5-nusasum`, jalan di Modal.

Preprocessing
Prompt `ringkas: `, input max 512 token, output max 80 token, greedy decoding.

Kapan dipakai
Jalur utama saat Modal reachable — hasil abstractive lebih natural daripada TextRank.

TextRank (fallback lokal)

Backbone
Non-neural extractive: TF-IDF sentence vectors + cosine similarity + PageRank.

Kapan dipakai
Kalau Modal tidak terjangkau — selalu tersedia selama sklearn/networkx terinstall, tidak butuh model eksternal.

Entity, Category, Urgency

NER
Cahya IndoBERT NER di Modal kalau reachable, fallback regex lokal untuk Jalan/Desa/Dinas/PLN/Puskesmas/Bapak/Ibu.

Category
Keyword matching 8 kategori: Infrastruktur, Kesehatan, Pendidikan, Keamanan, Lingkungan, Sosial, Administrasi, Umum. Selalu lokal.

Urgency
Weighted keyword scoring: critical/high/medium/low berdasarkan kata seperti darurat, korban, rusak parah, segera. Selalu lokal.

Environment Controls

Modal endpoint
`MODAL_START_URL` / `MODAL_HEALTH_URL` — di-set di environment backend setelah `modal deploy`.

Fallback translasi
`ALLOW_EXTERNAL_TRANSLATION` — bisa diatur lewat halaman Admin Settings tanpa redeploy.
